FX units are estimated only when the symbol is a six-letter FX pair and its quote currency matches the account currency. Metals, CFDs, and currency-converted pairs do not get a unit estimate because broker contract sizes and conversions must be verified. This is not an order ticket or financial advice.

Security: Client Secret, access tokens, and refresh tokens stay on the Supabase backend. The browser never receives the cTrader tokens. “Remove saved connection” deletes the encrypted token records in ScalpingBot; to revoke app access entirely, use cTrader ID / Open API application settings.
